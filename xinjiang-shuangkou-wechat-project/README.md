# 新疆双扣微信小程序入口

这个目录可以直接导入微信开发者工具。项目使用 AppID `wx2fe224c1164e9075`，首页通过 `web-view` 打开当前游戏页面，并保留房间邀请链接中的 `room` 参数。

## 导入

1. 打开微信开发者工具。
2. 选择导入项目。
3. 项目目录选择本目录。
4. AppID 使用 `wx2fe224c1164e9075`。
5. 在微信小程序后台的开发设置中，把游戏页面域名加入业务域名。

正式使用前，需要让游戏页面使用微信后台允许的 HTTPS 业务域名。当前 Site 地址写在 `pages/index/index.js` 的 `GAME_URL` 中，后续绑定自己的域名时修改这一处即可。
