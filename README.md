# 新疆双扣

本项目使用纯 TypeScript 规则引擎，支持单机人机、本地多人轮流和四人局域网房间。

## 运行

安装 Node.js 24 或更新版本后，在项目根目录执行：

```sh
node build.mjs
node server.mjs
```

然后打开 `http://127.0.0.1:4174`。

- 单机开局时选择 1–3 位真人，其余座位由人机补齐；也可选 4 位真人在同一设备上轮流操作。
- 四人异设备游玩时，由一台设备运行服务端并创建房间。服务端会打印局域网房间地址；另外三位玩家打开该地址输入房间号，四个座位到齐后由房主开始游戏。
- 房间牌局状态保存在服务端内存中，重启服务端后房间会清空。当前房间适用于同一局域网；跨公网访问需要部署到可访问的服务器，或自行配置网络转发。
- 玩家昵称可在开局设置或牌局顶部修改；人机座位按顺序显示为“人机1”“人机2”等。

默认房间邀请链接使用服务端检测到的局域网地址。如果需要指定链接里的主机名或 IP，可在启动前设置 `ROOM_HOST`；端口可用 `PORT` 修改。

规则测试使用 Vitest。安装 npm 依赖后运行 `npm test`。
